ast_grep 需求—设计链

用纯 Go 的 gotreesitter 为 go_hive 增加模型可调用的结构搜索工具。这个页面先冻结需求、决策、工具契约、匹配器和验收链，不把设计稿当成已实现能力。

状态：design决策：Implement ast_grep in Go with github.com/odvcencio/gotreesitter; keep CGO_ENABLED=0. Model path inputs are absolute-only and must resolve inside the workspace root.目标：CGO_ENABLED=0

00问题与价值

问题
go_hive has no model-facing structural code search tool. Regex search cannot match AST shape, captured metavariables, or multi-line syntax.
为什么不是当前 parity 项
This is a post-1.0, opt-in capability. Hive upstream has no ast_grep tool, so it is not part of the current parity surface.

用户价值

  • Find code by structure rather than exact text.
  • Use one tool across Go, Python, TypeScript, Rust, JSON, YAML and other supported grammars.
  • Keep the six-platform pure-Go build: no C toolchain, no cgo, no browser or Node sidecar.

非目标

  • Do not port omp-ast's editor/rewrite/staging engine in v1; read-only search only.

  • Do not promise byte-exact tree-sitter recovery on malformed source; gotreesitter publishes a measured parity scope, not universal equivalence.
  • Do not add ast_grep to the 1.0 parity claim; it is an opt-in post-1.0 capability.

03设计链

D1

Tool registration

ast_grep is opt-in and default-off. Registration is gated by ASTGrepEnabled(home), which reads only <home>/ast_grep.json (user; an empty home falls back to HIVE_HOME). There is no project/session-level file: the session directory is the file tools' sandbox root and is agent-writable, so reading <sessionDir>/.hive/ast_grep.json would let the model opt itself into a tool the operator left off (see go_hive/docs/config-roots.html). The file is a JSON object with a top-level boolean enabled; missing config means disabled, and malformed or unreadable config fails closed. There is no environment-variable override. When enabled, the model sees a normal tool definition in the lazy tier; a build tag is considered only if binary size becomes a problem.

D2

Dependency boundary

Add github.com/odvcencio/gotreesitter v0.57.x to go.mod. Import the grammar registry or selected grammar packages; never import a C binding. Keep a small language set in the default binary and make additional grammars opt-in if size demands it.

D3

Input contract

pat: string, required, trimmed, non-empty. path: absolute file, directory, glob, or semicolon-separated list inside the workspace root; default the workspace root. Relative paths are rejected. lang: optional canonical language override. skip: non-negative integer offset, default 0. No limit field in v1; the implementation caps visible results at 50 and pages with skip.

D4

Language registry

Resolve explicit lang through a canonical alias table. Otherwise infer from the filename through grammars.DetectLanguage. Unknown language or unsupported extension is a typed unsupported-language result, never a silent skip. .cu/.cuh map to cpp; .h needs an explicit lang when ambiguous.

D5

Pattern matcher

Parse the pattern with the same grammar as the candidate. Compile the pattern AST into a small matcher IR: node kind, field names, literal text, metavariable captures, wildcard, and variadic sequence. Walk candidate nodes with backtracking; repeated $NAME compares the captured source text; $$$NAME greedily consumes zero or more sibling nodes but backtracks to the next satisfiable match. Do not treat tree-sitter query syntax as ast-grep pattern syntax.

D6

Result renderer

Group by path, sort by path and byte offset, slice by skip, cap at 50. Render the same line-anchor shape as oh-my-pi: path header, *LINE:text anchors, continuation lines, optional meta: NAME=value, then a limit notice. No matches returns the explicit no-match string. Parse errors are reported separately and deduplicated.

D7

Safety boundary

Resolve every path under the session workspace; reject .. after cleaning; evaluate symlinks and reject targets outside the root. Skip binary files, files above the per-file cap, and VCS/cache directories. Semicolon entries are validated independently; one bad entry fails the request rather than silently dropping it.

D8

Execution model

Walk candidate files with a bounded worker pool; parse with a per-file timeout; retain only the current tree; release trees explicitly; stop on context cancellation. Cache compiled patterns per (language, pattern) within one call. Return a typed error for timeout, cancellation, parse-failure threshold and unsupported language.

D9

Path input is absolute

go_hive has no project cwd, so the model-facing path is absolute-only: the adapter splits the semicolon list, rejects an empty entry, and requires filepath.IsAbs on every entry before calling astgrep.Search. The core still resolves relative paths for standalone library callers and its own tests, but the tool contract does not. Absolute paths are resolved through symlinks before root containment so a symlinked workspace root (macOS /var -> /private/var) is accepted while a target outside the root is rejected.

Package 边界：internal/astgrep 是独立可测的核心包；internal/tools/builtin/ast_grep.go 只做工具 schema / 注册适配。The core package owns parsing, language detection, the structural matcher, path safety and result rendering. It must not import internal/server, internal/cli or internal/tools/builtin. The tool schema, registration and model-facing adapter live in the adapter package. 维护：Maintain astgrep as an independent Go package: its own API, doc.go, package tests, gofmt/size/lane-prefix gates, and a caller contract that can be exercised without a session or tool registry.

处理流水线

  1. normalize and validate pat/path/lang/skip
  2. resolve paths and infer languages
  3. compile pattern against the selected grammar
  4. walk candidates, parse with gotreesitter, run structural matcher
  5. capture metavariables and source ranges
  6. sort, dedupe, apply skip and 50-result cap
  7. render text + structured details
  8. release trees and return

04工具契约

输入 schema

{
  "type": "object",
  "additionalProperties": false,
  "properties": {
    "pat": {
      "type": "string",
      "description": "Single structural pattern using $NAME, $_, $$$NAME or $$$."
    },
    "path": {
      "type": "string",
      "description": "Absolute file, directory, glob or semicolon-separated list inside the workspace root; defaults to the workspace root. Relative paths are rejected."
    },
    "lang": {
      "type": "string",
      "description": "Optional canonical language override."
    },
    "skip": {
      "type": "integer",
      "minimum": 0,
      "description": "Match offset; defaults to 0."
    }
  },
  "required": [
    "pat"
  ]
}

输出

model-facing grouped matches, no-match or parse-error notice

details: matchCount, fileCount, filesSearched, limitReached, parseErrors, parseErrorsTotal, scopePath, searchPath

06实施阶段

  1. P0 — freeze requirements/contract and add dependency spike; prove gotreesitter parses the seven-language matrix with CGO_ENABLED=0.
  2. P1 — implement path/language resolution, parser pool and structural matcher with golden tests.
  3. P2 — implement result renderer, safety limits, cancellation and parse-error reporting.
  4. P3 — differential corpus vs ast-grep CLI, six-platform build, binary-size audit, opt-in config gate.
  5. P4 — promote from design to shipped only after A1-A11 pass on the release code point.

开放问题
