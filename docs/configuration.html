05优先级与覆盖

总规则：env > configuration.json > 内置默认。示例：HIVE_ADAPTIVE_TOOL_BUDGET、HIVE_STALL_CHECK、HIVE_MEMORY_TIMELINE、HIVE_RETENTION_<FIELD> 等。
规则契约status说明
general precedenceenv > configuration.json > built-in defaultalignedHolds for adaptive_tool_budget, email_senders, stall_check, memory_timeline and every HIVE_RETENTION_<FIELD>.
empty env stringfeature flags: empty/whitespace = not set -> fall through to configuration.json; retention bool fields: empty = falsealignedThe two rules are deliberately different; both runtimes implement the same split.
non-boolean env valuesdeny-list (0/false/no/off) -> false; any other non-empty value -> true. Not strconv.ParseBool.alignedSo HIVE_STALL_CHECK=disabled is TRUE on both sides. Documented as a boundary, not a bug to fix casually.
file value of the wrong JSON typeflag/section readers require the exact type; non-bool for a flag keeps the default; non-object section reads as emptyalignedJSON 1 is not a bool on either side (Go decodes to json.Number/float64; Python bool is a distinct type).
bad JSON / unreadable configuration.jsonread as {} -> every reader falls back to its default; a warning is logged on the Python sidealignedBoth strip a UTF-8 BOM; Go additionally rejects trailing JSON values after the object.
integer fields: invalid valueJSON: non-integer (bool/float/string) is ignored and the default/file value stays; env: invalid integer is ignored (Go) or warned+ignored (Python)alignedFloats like 7.0 are rejected by both (Python type mismatch; Go rejects decimal spellings).
