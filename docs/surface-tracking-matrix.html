关键外形差异：扁平 vs 分组

Python 把每个 action 注册成独立 MCP 工具：airtable_create_records、airtable_list_records … 共 865 个工具名。
Go 把每个集成注册成一个模块工具：airtable + action 参数（action: "airtable_create_records"），共 103 个工具名、863 个 action。
结论：能力覆盖对齐（99.8% action），但 工具名 / JSON schema 不是 1:1；依赖 Python 工具名的 prompt 需要改写，不能直接复用。逐模块明细见 tool-parity-matrix.html。
