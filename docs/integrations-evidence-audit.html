05缺口清单

5.1 跨模块系统性缺口

缺口事实与影响
OAuth refresh全包 0 处 refresh_token/grant_type=refresh。20 个凭据条目（17 个工具）只接受静态 access token；bigquery / google_analytics / google_search_console 支持 service-account JWT 换 token，reddit 支持 client-credentials 取 token，但都没有刷新循环。
分页integrationkit 的通用 REST 客户端没有分页原语；只有 bigquery 自动跟随 token，zoom/google_docs/gmail/google_maps/salesforce/stripe 做参数透传，其余列表 action 单页返回。
文件上传 / multipart全包无 multipart.NewWriter：slack 用 external upload URL + PUT 文本，microsoft_graph 用 4MB simple PUT，cloudinary 只接受 file_url，aws_s3 put_object 只接受文本。
webhook 验签无入站 webhook 接收器，因此也没有 HMAC/验签实现（工具面全部是出站客户端）。
多账号 / account 别名hubspot、obsidian、notion、discord、mattermost、google workspace、support_ats 多值 bundle 均单凭据；schema 里的 account 参数被忽略（上游 CredentialStoreAdapter 别名未复刻）。
二进制响应只有 microsoft_graph 下载（文本/base64）与 attach_file 图片块；其它模块按 JSON 处理。
测试真实性integration 包 0 个 t.Skip、0 个真实凭据环境变量读取、0 个外网调用；全部联网模块只用 httptest 或进程内协议假服务。
