00范围与判定口径

「外观」定义：「外观」= 一个实现对外承诺、且调用方（模型、用户、脚本、外部进程）能观察或依赖的全部契约。它是可观测契约的总和，不是内部架构、不是 UI 像素、不是性能。
不登记：不登记内部实现细节（锁粒度、数据结构、文件组织），除非它泄漏成可观察行为。
状态枚举值含义
已实测一致measured_aligned已实测一致：本次或可复现的既有实测，两侧在同一条输入下产生同一可观察结果；无未解释差异。
部分对齐partial部分对齐：主路径可达/存在，但有已量化或已命名的差异、缺口或未验证的边界。
有契约未验证contract_unverified有契约未验证：契约文件（schema/冻结产物/校验脚本）已存在，但没有对两侧实际行为跑过核对。
未对齐not_aligned未对齐：缺失或行为不成立。
未审计unaudited未审计：没有可用的对照证据，也没进任何矩阵；两侧实现是否存在等价性未知。
契约形态枚举值含义
冻结契约frozen_contract有机器可读的冻结契约 / 校验脚本（可重放、可 gate）。
只有文档doc_only只有散文/HTML 文档或代码注释描述，没有可执行的契约产物。
测试注解test_annotated只有 parity 测试注解或单侧测试，没有跨实现契约。
无none没有任何形式的对照契约。
