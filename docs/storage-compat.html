06凭据：格式与互读

两侧目录结构与加密格式一致：credentials/credentials/<id>.enc（Fernet token，明文是 CredentialObject JSON）+ credentials/metadata/index.json（INDEX_VERSION=2.0，无密钥）。Python 用 cryptography.fernet；Go 用标准库手写 Fernet（AES-128-CBC + HMAC-SHA256，同样的 key 切分与 token 布局）。

项PythonGo判定
加密cryptography.Fernet（标准 token）internal/credentials/fernet.go（标准 token）同格式
key 来源HIVE_CREDENTIAL_KEY / <home>/secrets/credential_key同一致
.enc 文件名<id>.enc（id 清洗 / \ ..）同一致
index.jsonversion/store_path/generated_at + credentials{...}，13 字段/条同键集（键顺序不同、时间戳格式不同）结构一致
双向互读Go 读 Python 写的 demo_api_key/demo_oauth；Python 读 Go 写的同两条 —— 值、expires_at、metadata、_alias/_integration_type/_identity_email 全部保留实测通过
文件权限目录 0755 / 文件 0644（默认 umask）目录 0700 / 文件 0600安全姿态差异（Go 更严）

证据：docs/storage-compat/credentials-crossread.json。残余语义点：provider_id Python 写 null，Go 是普通 string（读 null → ""），Go 回写后 Python 读到空串而非 None（仅显示层影响）。
