具体规则

07风险与建议

  1. 补契约：新增 contracts/skill-discovery.json（scopes/roots/priority/limits/skip_dirs/last_wins），配一条测试断言 discovery.py 的常量与扫描表 = 契约；Go 侧同一份契约做对位测试。否则每次加一个 scope 入口（如 preset、external_skills）都不会触发任何检查。
  2. 修文档：把 skills-user-guide.md 的 "five directories" 改成"6 类 scope + extra_scopes"，补 preset（默认关）、external_skills（配置键 + API）、queen_ui/colony_ui（UI 创建路径）；把 PRD 的 ".gitignore" 删掉或真正实现。
  3. 明确 .gitignore 语义：当前只有 _SKIP_DIRS；如果不打算实现，就要在 PRD 和 user guide 同时写清"不读取 .gitignore"。
  4. 安全提示入档：external_skills 属于 user scope、绕过 project trust gate——这应写进 user guide 的 trust 章节，而不是只存在于代码注释里。
  5. 保持 watcher 一致：scanned_directories 是热重载的目录来源；新增 scope 时若忘了加入 _scanned_dirs，watcher 会漏监听。
