## 亮点（本版相对 v1.0.26-go.1）

- **govulncheck 0 OSV**：工具链升 go1.26.11，23 条 stdlib CVE 清零（同 scanner/DB 对比证据）
- **崩溃恢复收口**：cold_interrupted 生产者对齐（上游探针 2 passed + 真实 kill -9 复现）；resume 快照/SSE 首帧带 `awaiting_input/park_reason/pending_questions`
- **recall 性能**：warm 查询 p50 **12.7ms**（原 123.8ms，9.7×；上游声称 ~30ms 的 2.4× 水平）；720 记录/7,194 轮 dump 逐字节相同
- **凭据端点补全**：`/api/credentials/check-agent` 与 `resync` 实装（13 字段行对齐；前端真实验证 200）
- **工具输入 coercion 接线**：派发前按 schema 强转（上游同点位：parse 后、tool_started 前）
- **存储契约**：SC-04 权限对齐（sessions 树 0600）、SC-06 sidecar API 双跑 0 差异、通配 `make storage-sweep`
- **MCP 别名层**（D3 标准版）：保留前缀 + 裸名单向回退，工具面 sha 不变
- **模块清单校正**：C12 273 = 217 ported / 27 partial / 9 oos / 20 unported（triage 修正 11 假标）

## 安装 / 升级 / 回滚

```bash
tar xzf hive-1.0.27-go.1-darwin-arm64.tar.gz   # 或对应平台
./install.sh                                    # 默认 ~/.local/bin；四二进制并列安装
~/.hive-go/start.sh                             # serve on 127.0.0.1:8788
```

- 升级：同一 `HIVE_HOME` 直接替换二进制；启动时自动跑 v1/v2/v3 迁移（保留备份）
- 回滚：换回旧二进制即可（迁移不删原文件）；slot 升级兼容 57 项已验
