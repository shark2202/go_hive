01配置

唯一配置位置

$HIVE_HOME/http_tools.json
  • macOS/Linux：~/.hive/http_tools.json
  • Windows：%USERPROFILE%\.hive\http_tools.json
  • 不读取 <sessionDir>/.hive/http_tools.json：会话目录是文件工具的沙箱根、agent 可写，自动发现会允许 agent 放宽自己的出站策略（提权）。
  • 配置在创建会话时读取；改完需要新建会话（或重启 serve）才生效。

默认配置（可直接复制）

{
  "enabled": true,
  "allow_private_hosts": false,
  "allowed_hosts": [],
  "denied_hosts": ["localhost", "*.localhost", "*.internal", "*.local", "metadata.google.internal"],
  "max_inline_bytes": 65536,
  "max_response_bytes": 16777216,
  "max_download_bytes": 1073741824,
  "max_upload_bytes": 1073741824,
  "default_timeout_seconds": 30,
  "max_timeout_seconds": 1800,
  "connect_timeout_seconds": 10,
  "follow_redirects": true,
  "max_redirects": 10,
  "allow_https_to_http": false,
  "user_agent": "hive-go/1.0 (+https://github.com/shark2202/go_hive)",
  "proxy": null,
  "redact_query_keys": ["token", "access_token", "refresh_token", "api_key", "key", "secret", "password", "sig", "signature"],
  "cookies": {
    "enabled": true,
    "host_only": true,
    "allowed_domains": [],
    "max_cookies": 200,
    "max_value_bytes": 4096
  }
}

本地调试（访问 localhost）

注意：默认 denied_hosts 含 localhost，且 denied_hosts 优先于 allow_private_hosts。只开 allow_private_hosts 不够，必须同时清空/移除 denied 项。
{
  "enabled": true,
  "allow_private_hosts": true,
  "denied_hosts": [],
  "allowed_hosts": ["127.0.0.1", "localhost", "::1"]
}

生产建议

{
  "enabled": true,
  "allowed_hosts": ["api.example.com", "*.trusted.example.com"],
  "allow_private_hosts": false,
  "max_inline_bytes": 32768,
  "max_download_bytes": 104857600
}

硬开关

HIVE_HTTP_TOOLS=0 hive serve    # 整组关闭

HIVE_HTTP_TOOLS=1 不会覆盖配置文件里的 enabled=false。

字段速查

字段作用
allow_private_hosts关闭私网/回环/CGNAT/ULA/metadata 拒绝（显式降级，记日志）
allowed_hosts / denied_hosts主机白/黑名单；denied 优先；allowed_hosts 非空时只允许名单内主机
max_inline_bytes / max_response_bytes内联预算（默认 64 KiB）/ 单次抓取硬上限（默认 16 MiB）
max_download_bytes / max_upload_bytes下载 / 上传上限（默认 1 GiB）
default_timeout_seconds / max_timeout_seconds默认总预算 / 总预算上限
connect_timeout_seconds连接预算（TCP + TLS）
follow_redirects / max_redirects / allow_https_to_http重定向策略；默认拒绝 https→http 降级
user_agent / proxy默认 UA / 显式代理（默认读 HTTP_PROXY/HTTPS_PROXY/NO_PROXY）
redact_query_keysURL 查询串中替换为 [redacted] 的键名
cookies.*本 Hive 会话 cookie jar 的总开关、host-only 默认、Domain 白名单与容量上限

路径规则（绝对路径）

没有相对路径：go_hive 只有会话沙箱根 c.root，没有项目 cwd。所有用户路径输入必须是绝对路径且在 c.root 内；相对路径返回 path_not_absolute，越界/../symlink 返回 path_escape。自动落盘（未给 path）由工具生成 <c.root>/data/tool-output/ 下的文件。
输入规则
response.path绝对路径；必须在 c.root 内；父目录自动创建。
http_download.path绝对目标文件；必须在 c.root 内；父目录自动创建；overwrite 控制覆盖。
http_upload.body_file绝对文件路径；必须在 c.root 内；流式读取。
http_upload.files[].path绝对文件路径；必须在 c.root 内；流式上传。
tls.ca_file / client_cert_file / client_key_file绝对路径；必须在 c.root 内；通过 os.Root 打开。
自动落盘（未给 path）<c.root>/data/tool-output/http_<hash>.bin；saved_to 为绝对路径。

02加载方式

默认 flat 模式下，这三支工具不在冻结的 39 个默认面，只进 lazy/searchable 层。三种加载方式：

  1. 按名加载（推荐）：search_tools("select:http_request,http_download,http_upload")，加载后同一会话内直接调用。
  2. 关键词加载：search_tools("http request")。
  3. 直接可见：HIVE_TOOL_SURFACE=grouped hive serve，或把名字写进 queen 的 tools.json 的 enabled_mcp_tools（已有 sidecar 由 CategoryAdditions["web_core"] 自动愈合）。
为什么不进默认 39？保持参考工具面（builtin 14 / flat 39 / 首轮 24）不变。三支工具是 go-only 增量，走 lazy 层即可按需加载。

03调用示例

http_request

{
  "url": "https://api.github.com/repos/shark2202/go_hive",
  "headers": {"Accept": "application/vnd.github+json"}
}
{
  "url": "https://httpbin.org/post",
  "method": "POST",
  "json": {"hello": "world"},
  "timeout_seconds": 20
}
{
  "url": "https://api.example.com/v1/me",
  "auth": {"type": "bearer", "token": "<token>"}
}
{
  "url": "https://example.com/big.json",
  "response": {"mode": "auto", "path": "/abs/session/downloads/big.json"}
}

http_download

{
  "url": "https://example.com/file.zip",
  "path": "/abs/session/downloads/file.zip",
  "resume": true,
  "expected_sha256": "<sha256>"
}

结果含 path、bytes、sha256、resumed、etag、last_modified。写入 <path>.part，fsync 后原子 rename。

http_upload

{
  "url": "https://httpbin.org/post",
  "fields": {"name": "demo"},
  "files": [{"field": "file", "path": "/abs/session/downloads/file.zip"}]
}
{
  "url": "https://httpbin.org/put",
  "body_file": "/abs/session/downloads/file.zip",
  "content_type": "application/zip"
}

files 从 workspace 流式读取；body_file 为原始 body（默认 PUT）。文件名会净化（去掉路径与 ..）。

Cookie（登录态）

{
  "url": "https://example.com/login",
  "method": "POST",
  "form": {"user": "u", "pass": "p"},
  "cookies": {"jar": "session"}
}
  • 同一 Hive 会话后续调用自动带 cookie；
  • cookies.clear: true 登出；
  • cookies.jar: "none" 无状态；
  • 跨会话、跨 worker 不共享（WithRoot 新建空 jar）；
  • 默认 host-only，Domain cookie 需 cookies.allowed_domains 显式放行；
  • v1 不落盘，恢复会话从空开始（需重新登录）。

04结果与排错

三支工具统一返回 JSON 信封：

{
  "tool": "http_request",
  "url": "https://...",
  "final_url": "https://...",
  "method": "GET",
  "status": 200,
  "ok": true,
  "headers": {"content-type": ["application/json"]},
  "body": "...",
  "body_encoding": "utf8",
  "body_bytes": 123,
  "body_sha256": "...",
  "saved_to": null,
  "timing_ms": {"total": 123, "dns": 5, "connect": 20, "tls": 30, "first_byte": 80},
  "tls": {"version": "TLSv1.3", "subject": "..."},
  "redirects": [],
  "cookies_rejected": 0,
  "error": null,
  "error_kind": null
}
error_kind处理
ssrf_blocked目标被出站策略拒绝；本地调试见上面的 allow_private_hosts + denied_hosts: []
timeout调大 timeout_seconds / default_timeout_seconds
response_too_large调大 max_response_bytes / max_bytes
too_many_redirects调大 max_redirects
https_downgrade_blocked需要时显式 allow_https_to_http: true
cookie_jar_invalidcookies.jar 只能是 session 或 none
checksum_mismatch下载内容与 expected_sha256 不一致；.part 保留可重试
path_not_absolute用户路径不是绝对路径；改成会话根内的绝对路径
path_escape绝对路径逃逸出会话根（.. / symlink）；改到根内
write_failed目标已存在（overwrite=false）或写失败；检查 path/overwrite

05安全边界

  • 仅允许 http/https；拒绝回环/私网/链路本地/CGNAT/ULA/metadata 主机名。
  • 解析后拨号已验证 IP，DNS rebinding 无法在校验与连接之间换成私网地址。
  • 每一跳重定向重新校验；跨主机剥离 Authorization/Cookie；默认拒绝 https→http。
  • 结果与日志脱敏；Set-Cookie 默认隐藏；响应头/体有上限。
  • 这是护栏，不是沙箱：terminal_exec 仍可写 HIVE_HOME 或直接跑 curl；高安全部署应同时限制 terminal 工具。
