④ MCP 服务器（可选，用户自带）

  • 配置：~/.hive/mcp_registry/installed.json + configuration.json 的 mcp 块
  • 传输：stdio（子进程）或 HTTP/SSE；工具命名 mcp__<server>__<tool>
  • 为什么：把外部工具生态接进会话，而不写进内置 41 个工具
  • 风险：stdio 服务器继承当前用户权限；未配置白名单时 MCP 工具默认可见

⑥ 网络扫描器（默认注册）

ssl_tls_scan、http_headers_scan、dns_security_scan、port_scan、subdomain_enumerate、tech_stack_detect（以及消费其输出的 risk_score）主动探测目标。与上游一致，默认注册、没有开关；会向模型指定的主机发 TCP/TLS/HTTP/DNS 流量，调用方只能扫描已获授权的目标。

⑦ 本地 / 系统依赖（部署必需，不是外部 API）

依赖用途
文件系统 ~/.hive/queens / colonies / sessions / credentials / soul / tracker 全部状态；可用 HIVE_HOME 改根
SQLite（modernc）tracker、任务、凭据元数据；纯 Go，无 cgo
HIVE_CREDENTIAL_KEY凭据加密；丢失则已存凭据不可解
进程 / 端口hive serve、MCP 子进程、工具执行；默认 127.0.0.1
Go 直接依赖为什么
modernc.org/sqlite无 cgo 的 SQLite，六平台交叉编译
purego无 cgo 调用系统库（终端/系统能力）
go-isattyCLI 交互检测
yaml.v3配置与 playbook 解析
前端构建期内嵌，无 CDN 运行时依赖

⑧ 验证状态与风险

  • 已真实验证：LLM（DeepSeek 兼容网关）、MCP（1 个服务器 2 工具）、26 个免凭据模块、SMTP 仅单元测试（未真实发信）。
  • 未验证：77 个凭据型模块 / 118 条凭据；本阶段未提供第三方凭据。
  • 行为限制：MiniMax 不流式（chunk 破坏解析，已测试锁定回退）；Python playbook 不可执行；Queen/overseer 两份 conversation 存储。
  • 出网：任意 URL 抓取工具让目标不受限；扫描器默认注册、会向指定目标探测（仅限已获授权目标）；MCP 无 OS 沙箱。
  • 密钥：凭据仅存本机加密库；HTTP 响应与日志不含明文，credential_status 只返回元数据。

⑨ 维护方式

  • 凭据变化：uv run --no-project python go_hive/scripts/gen_credential_specs.py 重新生成 specs_gen.go，再更新本文与 MD 版。
  • 端点变化：改 internal/llm/keycheck.go、internal/tools/integrations/*registry*.go、internal/senders/sender.go，同步本文件。
  • 架构关系见 docs/architecture/capability-tech-crosswalk.md 的“工具与凭据边界”。
