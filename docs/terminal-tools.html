终端工具 terminal-tools

Hive 的终端能力是一组 harness 组 terminal-tools：10 个工具、进程内执行（不是 MCP 子进程），默认 queen 就包含这一组，默认会话能直接看到它们。本页登记工具面、参数、边界（截断/后台/PTY/平台差异）与代码位置；机制以代码为准，Python 与 Go 同名。

02机制

有界输出 + handle
不丢数据
exec/job 的每路输出有上限；超出即截断并返回 handle，用 terminal_output_get 按 since_offset 续读。
自动转后台
auto_background
terminal_exec 的 auto_background_after_sec：命令跑超时即转成 job，返回 job_id 继续跟踪，不再阻塞。
shell 语义自动检测
管道即可靠
命令含管道/重定向等 shell 语法时自动走平台 shell（Python：POSIX /bin/bash；Windows Git Bash→PowerShell→cmd）；zsh 明确拒绝（安全立场）。

PTY 会话语义

  • 一个会话绑定一个持久 bash；同一会话的 run 串行（忙时拒绝并发调用），状态（env、cd、REPL）跨调用保留。
  • 有 idle 超时（默认 1800s，可配 idle_timeout_sec）与会话数上限（env TERMINAL_TOOLS_MAX_PTY）。
  • 用完必须 terminal_pty_close；宿主退出时统一回收（atexit）。

搜索类

  • terminal_rg：ripgrep 优先；allow_fallback 控制找不到 rg 时的降级路径；Windows 有独立的 rg 安装发现逻辑。
  • terminal_glob：按名字/glob 枚举文件，include_ignored 决定是否包含 ignore 规则命中的文件。

03平台差异

能力macOS / LinuxWindows
exec / job可用（bash）Python：可用（Git Bash→PowerShell→cmd 解析）；Go 当前不可用：internal/tools/builtin/exec.go 硬编码 /bin/bash（job 工具有正确解析）
PTY 三件套可用明确不支持：调用返回 terminal_pty_* tools are POSIX-only; not supported on Windows（工具仍在位，保持工具面一致；Python/Go 文案逐字相同）
进程终止语义进程组 SIGKILL（连带子进程）无 POSIX 进程组；Go 只杀直接进程（孙进程不覆盖），Python 的 Claude Code 树用 taskkill /T
ripgrepPATH 或安装发现有独立安装发现逻辑（含专用测试）
PLAT-01（已知缺口）：Go 的 terminal_exec 在原生 Windows 上启动 /bin/bash 会失败；这是 go_hive 侧未对齐项，Python 不受影响。详见 platform-support.html。

04安全与生命周期

  • 命令守卫只拦「杀/启动浏览器进程」（runtime 和用户拥有浏览器生命周期，bridge 是连到用户已开的 Chrome）；其余命令放行，属于"受信 agent + 宿主权限"模型，不是沙箱。
  • 回收：后台 job 与 PTY 会话在宿主退出时统一 shutdown（原 MCP server lifespan 的职责，进程内化后由 atexit 承担）。
  • 作用域：会话的工具集受 allowlist / colony gating 控制；worker 的工具面由 queen 派活时裁剪（剥掉 queen 生命周期工具）。
  • 输出对模型的影响：截断 + handle 机制防止一次调用把上下文灌满；max_output_kb 可在调用级收窄。
