§3 驱动回路

trigger（timer / playbook）
   → queen marshal（goal 分解为任务 / 派 worker）
   → worker 执行（worker.json 可带 success_criteria）
   → OutcomeAggregator 聚合（OutcomeAggregator.__init__, OutcomeAggregator.record_decision, OutcomeAggregator.record_outcome, OutcomeAggregator.evaluate_goal_progress, OutcomeAggregator.get_stats）
   → agentloop goal_eval 按成功标准×权重判定（加权比例，LLM judge 可参与）
   → 未达标 → 重试 / 升级；达标 → 推进 / 结束
（宿主 = colony runtime：core/framework/host/colony_runtime.py 持有 overall goal 与 get_goal_progress）

orchestrator 侧方法：Goal.is_success · Goal.to_prompt_context（to_prompt_context 把目标与约束注入模型上下文）。

§6 使用方式与入口

  • colony 带目标：建 colony 时带 overall Goal；trigger（timer/playbook）驱动长跑；进度经 get_goal_progress 暴露。
  • 单聊不跑 goal：queen chat 是对话驱动；目标体系只在 colony 多体场景生效。
  • 无 CLI 子命令：hive 现有 10 个子命令（serve、open、queen、colony、session、chat、skill、debugger、mcp、janitor），不含 goal；管理走 colony 配置/queen 工具链。
  • worker 级标准：worker.json 的 success_criteria 进 judge；colony 级进 goal_eval。
