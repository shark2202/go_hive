GO_HIVE · LSP · USER GUIDE

lsp 使用手册

go_hive 通过纯 Go 的 stdio JSON-RPC 客户端接入你本机安装的语言服务器，提供只读的语义导航、类型信息、引用查询和诊断。语言服务器是外部运行时依赖，不随 go_hive 发布包分发；模型不能选择服务器命令或参数。

00快速开始

Step 1

装语言服务器

按语言安装 gopls、pyright、typescript-language-server、jdtls。服务器不在 PATH 时，配置里写绝对路径。

Step 2

构建 go_hive

make build 产出 dist/hive；LSP 客户端只用 Go 标准库，不需要新依赖或 cgo。

Step 3

写 lsp.json

用户级 $HIVE_HOME/lsp.json 或项目级 <cwd>/.hive/lsp.json，至少包含 settings.enabled=true。

Step 4

确定工作区根

默认在会话 cwd 查找 root marker；queen 会话 cwd 是独立 session 目录时，在对应 server 上配置绝对 rootDir 指向项目根。

Step 5

先查 status

调用 {"action":"status"}，确认目标服务器为 available，再执行 definition/references/diagnostics。

Step 6

改配置后重开会话

v1 不暴露 reload 动作；修改 lsp.json 或 root marker 后重新建立会话。

注册条件：lsp 工具只在 settings.enabled=true 时进入会话工具目录，并且属于 lazy tier。关闭该开关后，工具面完全不出现。

01构建环境

依赖用途要求
Go编译 go_hive与仓库 go.mod 一致的 Go 工具链；实测 Go 1.26.x。LSP 客户端为纯标准库实现。
Node.js / npmPyright 与 TypeScript 语言服务器Node 20+ 可用即可；本手册使用用户目录前缀安装，避免写系统级 npm。
JDKEclipse JDT LSJDK 21+；Homebrew 的 jdtls 启动封装会自动指向 /opt/homebrew/opt/openjdk。
语言服务器真正的语义能力不由 go_hive 捆绑；缺失时 status 显示 missing，不会伪造结果。

构建与测试

cd go_hive/go-hive
make build                 # 产出 dist/hive
CGO_ENABLED=0 go build -o dist/hive ./cmd/hive
make ci                    # fmt / vet / test / cross / parity / wiring 全量门禁

只跑 LSP 相关测试

go test ./internal/lsp/... ./internal/tools/builtin/... ./internal/cli/...
发布边界：go_hive 二进制只包含客户端。语言服务器由用户安装、由配置指定；服务器崩溃或缺失会返回可读失败，不会退回文本搜索冒充语义结果。

02安装语言服务器

macOS（Homebrew + 用户目录 npm）

# Go + Java
brew install gopls jdtls

# Python + JavaScript/TypeScript（装到用户目录，不动系统 npm）
mkdir -p "$HOME/.hive/lsp-servers"
npm install --prefix "$HOME/.hive/lsp-servers" \
  pyright typescript@5.9 typescript-language-server
TypeScript 版本：请使用 typescript@5.x。TypeScript 7.x 的包布局不再包含语言服务器需要的 lib/tsserver.js，typescript-language-server 会在 initialize 阶段报 “Could not find a valid TypeScript installation”。

其他安装方式

# Go
go install golang.org/x/tools/gopls@latest

# Python（也可用 pipx）
pipx install pyright

# Java：任意 JDK 21+ 发行版；使用 brew 时 jdtls 会自动设置 JAVA_HOME
brew install openjdk jdtls

命令解析顺序

配置里的 command 只能是裸命令名或绝对路径，相对路径会被拒绝。解析顺序是项目本地目录优先，最后才查 PATH：

<cwd>/.hive/bin
<cwd>/node_modules/.bin
<cwd>/.venv/bin
<cwd>/venv/bin
<cwd>/bin
PATH

如果服务器装在用户目录且不在 PATH（例如 ~/.hive/lsp-servers/node_modules/.bin），请在配置中写绝对路径。

03配置

文件与优先级

层级路径说明
built-in嵌入的 internal/lsp/defaults.json始终加载，当前含 7 个定义：bashls、clangd、gopls、pyright、rust-analyzer、typescript-language-server、yamlls。
user$HIVE_HOME/lsp.json由启动环境决定；本机实际为 /Users/mac/.hive-go/lsp.json，不是 ~/.hive_go。
project<cwd>/.hive/lsp.json随项目提交，团队共享。
local<cwd>/.hive/lsp.local.json机器本地覆盖，建议加入 .gitignore。

合并规则：所有存在的文件都参与合并，不是 first-file-only。优先级 built-in < user < project < local。每个服务器对象按字段浅合并；settings、initOptions 这类对象字段整体替换，不做深合并。高优先级文件未出现的服务器保留低优先级定义。

settings

字段默认说明
enabledtrue总开关；false 时 lsp 工具不注册。
lazytrue工具定义进入 lazy tier；首次非 status 调用才创建服务器进程。
requestTimeout10单请求秒数，允许 1..300；超出范围会告警并沿用默认。
formatOnWritefalse写盘后格式化。v1 只读，该开关不改变工具面。
diagnosticsOnWritetrue写盘后收集诊断；v1 只读，供后续写动作使用。
diagnosticsOnEditfalse编辑后收集诊断；v1 只读。
sharedfalse共享服务器进程；v1 默认每个 project + server 独立进程。
idleTimeoutMs300000空闲客户端/文档回收时间，允许 1000..86400000。

服务器字段

字段必填说明
command是裸命令名或绝对路径；拒绝相对路径、.. 和 shell 元字符。
fileTypes是扩展名数组，必须带点，如 [".go",".mod"]。
rootMarkers是相对路径数组，只在当前工作目录查找，不向父目录遍历；配置 rootDir 时在该目录查找。
rootDir否绝对、存在、无 .. 的目录。设置后该 server 的工作区根固定到此目录；未设置时按 cwd-only rootMarkers。queen 会话隔离 cwd 时用它指向项目根。
args否参数数组，最多 64 项，每项最多 2048 字节。
languageId否LSP languageId；未设置时按扩展名推断。
initOptions否initialize 时传给服务器的 initializationOptions，整体替换。
settings否服务器专属设置，整体替换。
disabled否禁用该服务器，保留定义便于快速恢复。
warmupTimeoutMs否initialize 等待上限，0..60000，默认 5000。
isLinter否标记为 linter；同一扩展名同时匹配多个服务器时优先非 linter。
watchFiles否服务器关注的配置文件列表，用于变更检测。

03arootDir 工作区

默认规则是 cwd-only：服务器只在会话当前目录查找 rootMarkers，不会向父目录遍历。queen DM 会话的 cwd 是它自己的 session 目录（例如 ~/.hive-go/queens/<queen>/sessions/<id>），所以即使项目就在机器上，默认也会显示 unrooted。

给单个 server 配置 rootDir 后，该 server 的发现、project-local bin、进程 cwd、initialize 的 rootUri、文档管理器和 workspace 扫描都改用这个根。不同 server 可以指向不同项目根；不要为 Go 和 TypeScript 强行共用一个根。

{
  "servers": {
    "gopls": {
      "command": "/opt/homebrew/bin/gopls",
      "rootDir": "/Users/you/work/repo/go_hive/go-hive",
      "args": ["serve"],
      "fileTypes": [".go", ".mod", ".sum", ".work"],
      "rootMarkers": ["go.mod", "go.work", "go.sum"]
    },
    "pyright": {
      "command": "/Users/you/.hive/lsp-servers/node_modules/.bin/pyright-langserver",
      "rootDir": "/Users/you/work/repo",
      "args": ["--stdio"],
      "fileTypes": [".py", ".pyi"],
      "rootMarkers": ["pyproject.toml", "pyrightconfig.json", "setup.py"]
    },
    "typescript-language-server": {
      "command": "/Users/you/.hive/lsp-servers/node_modules/.bin/typescript-language-server",
      "rootDir": "/Users/you/work/repo/core/frontend",
      "args": ["--stdio"],
      "fileTypes": [".ts", ".tsx", ".js", ".jsx"],
      "rootMarkers": ["tsconfig.json", "jsconfig.json", "package.json"]
    }
  }
}
规则说明
绝对路径rootDir 必须是绝对路径；相对路径和 .. 会被拒绝。
必须存在目录不存在时该 server 保持 unrooted，并给出 rootDir ... does not exist 原因，不会退回 session 根。
每个 server 独立根只作用于当前 server；三个语言可以各自指向 Go module、repo 根和 frontend 根。
文件路径请求里的相对 file 相对该 server 的 rootDir；绝对路径仍会校验必须落在该根内。
workspace 扫描file="*" 的 diagnostics/symbols 只扫描该 server 的 rootDir，不会扫描整个 HIVE_HOME。
配置生效v1 不暴露 reload；修改 rootDir 后重新建立会话。已有会话若仍持有旧配置，以新会话为准。
本机实测：在 /Users/mac/.hive-go/lsp.json 中给 gopls 配 /Users/mac/hive/go_hive/go-hive、pyright 配 /Users/mac/hive、typescript-language-server 配 /Users/mac/hive/core/frontend 后，queen DM 会话 lsp status 显示 3 available，并可直接查到 Go/Python/TS 符号。

04使用

入口是会话内的工具名 lsp，不是独立 CLI 子命令。工具定义由 CLI 会话目录注册，调用经 internal/tools/builtin 适配器进入 internal/lsp 服务。lsp 属于 lazy tier：会话里先用 search_tools（例如 query select:lsp）加载，之后才能调用。

动作与参数

action作用必填备注
status配置来源、服务器状态、可用/运行/失败计数无不启动服务器
capabilities查看服务器协商出的 capabilities无可能启动服务器
diagnostics单文件或工作区诊断file工作区用 file="*"
definition符号定义位置file, line + 符号或列可传 symbol
type_definition类型定义位置同上
implementation实现位置同上
references引用位置同上默认最多 50 条
hover悬停信息/类型签名同上文本上限 4000 字节
symbols文档符号或工作区符号file工作区用 file="*" + query
参数类型说明
actionstring必填；只接受上述 9 个只读动作，未知动作报 invalid_argument。
filestring工作区相对路径或绝对路径；status、capabilities 不需要；* 只用于 diagnostics 和 symbols。
lineinteger1-based；位置类动作必填。
columninteger1-based；省略 symbol 时使用，默认 1。
symbolstring该行上的标识符；name#2 选择第 2 次出现；先区分大小写匹配，再忽略大小写。
querystring工作区符号查询词，配合 file="*" 的 symbols。
timeoutinteger整体超时秒数，5..300，默认 20。

调用示例

{"action": "status"}

{"action": "definition", "file": "internal/lsp/service.go",
 "line": 42, "symbol": "NewService"}

{"action": "references", "file": "a.ts", "line": 1, "symbol": "x"}

{"action": "hover", "file": "src/main/java/Demo.java",
 "line": 3, "column": 20}

{"action": "diagnostics", "file": "a.py"}

{"action": "symbols", "file": "*", "query": "Colony"}

{"action": "diagnostics", "file": "*", "timeout": 120}

status 的服务器状态

状态含义与处理
available已找到 root marker，或已配置有效的绝对 rootDir，且命令可执行，可以使用。
running进程已启动；括号内显示空闲时长。
unrooted当前 cwd 找不到该 server 的 root marker，且未配置有效 rootDir；在项目根启动会话，或为该 server 配置绝对 rootDir。
missing命令无法解析；安装服务器或在配置中写绝对路径。
disabled配置中 disabled=true；删除该字段或设为 false。
failed初始化失败并进入退避；查看 lastError 与服务器 stderr 尾部。

06排障

常见问题

现象处理
status 显示 unrootedroot marker 只在 cwd 查找。切换到含 go.mod/pyproject.toml/package.json/pom.xml 的项目根再启动会话，或为该 server 配置绝对 rootDir（推荐用于 queen 会话）；检查目录真实存在。
status 显示 missing命令不在 PATH。安装服务器，或在配置中把 command 写成绝对路径；确认文件有可执行权限。
typescript：Could not find a valid TypeScript installationTypeScript 7.x 缺少 lib/tsserver.js。安装 typescript@5.9，并确保与 typescript-language-server 在同一前缀。
jdtls 启动失败或找不到 Java需要 JDK 21+。非 brew 安装时设置 JAVA_HOME；brew 的 jdtls 封装已自动处理。
改了配置但行为没变v1 不暴露 reload；重新建立会话。确认修改的是正确的层级，并检查 status 的 config 来源列表。
项目里出现 .hive/jdtls-workspace这是 jdtls 的 per-project 数据目录；加入 .gitignore，或把 -data 改成项目外的绝对路径。
首次请求很慢lazy 模式下首次非 status 调用才启动服务器；gopls 与 jdtls 需要索引/导入项目。可把 timeout 调到 60..120。

错误码

code含义
invalid_argument动作或字段非法，例如缺少 file/line、file="*" 用在了位置类动作。
unsupported_action动作属于设计中的写/控制面，v1 未暴露：rename、code_actions、rename_file、reload、request。
disabledsettings.enabled=false。
no_server没有匹配该文件的服务器，或匹配到的服务器不可用。
server_unavailable进程启动失败；消息含原因与有界 stderr 尾部。
request_failed服务器返回 JSON-RPC error。
timeout请求超过 timeout 或 requestTimeout。
path_rejected路径逃出工作区、不是普通文件、或符号链接检查失败。
position_rejected行号或符号无法解析；检查 1-based 行号与标识符拼写。
unsupported_by_server服务器协商能力不包含该动作，例如没有 referencesProvider。
internal本地意外失败；保留 status 输出与 stderr 以便排查。

07安全与边界

只读 v1

没有写动作

rename、code actions、文件重命名、原始 request 都不在工具 schema 内；模型无法通过这些路径改文件。所有暴露动作自动执行。

命令信任边界

模型不能选二进制

服务器命令和参数只来自内置目录或用户/项目配置；模型输入只影响文件、行、符号、查询和超时。

路径边界

工作区内普通文件

拒绝逃出工作区的路径、非普通文件和符号链接检查失败；不把 Go 字节偏移当作 LSP UTF-16 列。

资源上限

有界等待与输出

请求与工具超时、进程数上限、结果条数与字节上限；服务器 stderr 只保留有界尾部，不进入正常结果。

上限值作用
工具超时5..300s，默认 20s单次 lsp 调用总预算。
请求超时1..300s，默认 10ssettings.requestTimeout。
references / symbols50 / 200单次返回的引用与文档符号上限。
workspace symbols / files200 / 20工作区符号与扫描文件上限。
diagnostics200单次诊断条数上限。
hover / result4000 B / 64 KiB悬停文本与整体结果字节上限。
running processes / checkers8 / 2同时运行的服务器与工作区检查器上限。
