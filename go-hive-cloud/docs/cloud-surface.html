07缺口 / 未知（不得虚构）

  • Real cloud 401 body: observed-contract says {error:signed_out}; the client copy is the verbatim sentence (implemented).
  • JWT issuer, signing algorithm, claims and login/device flow.
  • GET /v1/inbox/stream (desktop SSE): event names and payloads.
  • Inbox desktop/web UI endpoints (GET /v1/inbox/messages, POST /v1/inbox/messages/{id}/reply, POST .../{id}/read, POST .../mark-all-read, GET .../unread-count): paths named in docs/internal/hive-inbox-design.md §8 and go_hive/docs/hive-inbox.html §02, but request/response shapes are not in observed-contract.json — registered unknown, deliberately not implemented.
  • POST /v1/inbox/runtime/heartbeat: documented upstream but the runtime never calls it; request/response UNKNOWN.
  • Inbox runtime stream `kind` filter semantics: upstream filtering is UNKNOWN; this module records kind as connection bookkeeping only.
  • Inbox read-state/unread-count model (inbox_message_reads) and list pagination: UNKNOWN; no endpoint implemented.
  • POST /user/refresh-stream-token (desktop legacy): request/response.
  • streamToken revocation: no sid blacklist or revocation ledger is observable. This module has none; an unexpired token stays valid after rotation, and the only revocation lever is removing a signing secret (master-secret rotation, dual-key window).
  • streamToken/direct JWT claims beyond user_id, team_id, typ, iss, iat, exp: the real cloud signer, issuer and login/device flow are UNKNOWN.
  • LLM proxy internal semantics: model routing, billing, rate limits, provider-key selection and the exact upstream 401 message are UNKNOWN. M5 forwards the request body/model and the upstream status/body verbatim to an explicitly configured upstream; it has no routing table and does not mint provider keys.
  • Anthropic SSE event subset of the real cloud: UNKNOWN. M5 relays whatever `text/event-stream` bytes the configured upstream produces (line-by-line, flushed per line) instead of enumerating event names.
  • Image generation backend/model/format: UNKNOWN. M5 forwards the observed JSON client contract (prompt/model/size/quality/n/output_format/image[]) to an explicitly configured OpenAI-compatible images endpoint; it does not implement OpenAI multipart edits itself.
  • LLM proxy refresh TTL/rotation policy on the real cloud: 24h is the client-observed TTL; server internals UNKNOWN.
  • CRM entity schema, stage rules and claim/release semantics.
  • Senders send-log/setup HTTP paths: 8 client methods, no server code in the OSS repo.
  • Aden credential refresh/validate payload details.
  • Gateway availability host attribution: hive-backend vs api.adenhq.com.
  • cloud_sync reconcile protocol (not in go-hive-cloud scope).

unknown 项只有在拿到源码锚点后才能升级为 inferred/planned/implemented；升级时必须同时改本生成器的 curated 表与 source_anchors。
