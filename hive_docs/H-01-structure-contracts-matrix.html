0. 一句话结论

Hive 的静态结构是“一个执行原语 + 一层控制平面 + 一组入口”：所有角色最终都落到 AgentLoop.execute(ctx)；差异不在“另一个引擎”，而在 AgentSpec/AgentContext 的装配、工具表、预算、持久化目录 与 谁可以调用谁。功能契约大多是 Python 类型 + JSON Schema + 事件；真正的边界由少量运行时检查拼成。

2. 依赖方向

core/hive（公开面）
  └─ framework.agent_loop / llm / host / loader / server.channels / server.turn_context

server（HTTP/会话/编排）
  └─ agents.queen / host / agent_loop / llm / skills / storage / tasks / credentials / tracker

host（Colony/Worker/Playbook/EventBus）
  └─ agent_loop / llm / tools / storage / skills / tasks / tracker

agent_loop（执行内核）
  └─ llm / loader.tool_registry / storage / tasks / tracker

orchestrator（legacy 图）
  └─ agent_loop / llm / loader

tools / skills / credentials / storage（基础能力）
  └─ config / schemas / utils

没有 import-linter/分层门禁；依赖方向靠约定与代码评审维持。legacy orchestrator 与 agent_loop 是两条并行执行路径。

6. 预算/失败/权限矩阵（摘要）

预算

  • 迭代：Queen 无限；Worker 3+1 grace。
  • 每回合：Queen 30×5=150；Colony 50×10=500；Worker 30×3=90。
  • 生命周期：Worker 200；Queen 0（可覆盖）。
  • 上下文：180k 默认；压缩先于 LLM。
  • 时间：TTFT 600s；事件间 120s；工具 60/180/240/235s。

失败

  • LLM transient 5 次；capacity 600s；其它停泊。
  • 工具错误只标记 is_error，不自动重试。
  • 死循环 3 次指纹；文本停顿 3 次/0.85。
  • Worker 超时软 600s / 硬 3600s 上限。
  • Sentinel 默认 continue。

权限

  • Queen-only 20 个工具；Worker 继承 6 个。
  • MCP allowlist + eager/searchable。
  • tool_access_policy 仅图节点生效。
  • 技能 allowed-tools 不执行。
  • 无沙箱：终端/Playbook/浏览器 = 宿主权限。

真相

  • 会话 parts+cursor：继续运行必需。
  • tracker.db：业务事实。
  • tasks.json：意图。
  • events.jsonl：审计/回放。
  • memory/Soul/profile：连续性。
  • 凭据：加密存储。
