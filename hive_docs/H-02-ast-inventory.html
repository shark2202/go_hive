6. 如何维护

生成

uv run python scripts/gen_ast_inventory.py \
  --root /Users/mac/hive \
  --out hive_docs/ast-inventory.json
  • 输出：模块、行数、imports、类（基类/方法数）、顶层函数、docstring、内部边、SCC、fingerprint。
  • 确定性：除 generated_at 外全部排序；fingerprint 对其余内容做 sha256。

CI 漂移检查

uv run python scripts/gen_ast_inventory.py \
  --root /Users/mac/hive \
  --out hive_docs/ast-inventory.json \
  --check
  • 指纹不一致 → 退出 1，提示重跑。
  • 已实测：生成后立即 --check 返回 0。
  • 建议挂在 pre-commit 或 CI 的文档/契约门禁。
