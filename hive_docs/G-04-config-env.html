1. 加载顺序与优先级

顺序

  • HIVE_HOME（env）决定根目录，默认 ~/.hive。
  • 根目录下 configuration.json 提供显式配置。
  • 缺失时走 dataclass/dict 默认值。
  • 部分 getter 再读 env 覆盖（如 HIVE_STALL_CHECK、HIVE_MEMORY_RECALL）。

热更新

  • 大多数 getter 每次调用重新读取 config/env，属于“读时解析”。
  • 少数在导入时固定：HIVE_HOME、HIVE_DESKTOP_TOKEN、HIVE_CONFIG_FILE。
  • 改 HIVE_HOME / 桌面 token 必须重启进程。

7. 漂移与缺口

已确认的文档漂移

  • HIVE_CONFIG_FILE：12 章说是环境变量，代码是 HIVE_HOME / "configuration.json" 常量。
  • HIVE_API_BASE：12 章列为 env，代码只是 HIVE_LLM_ENDPOINT 的本地别名。
  • HIVE_LLM_ENDPOINT：是常量 URL，不是 env。
  • 旧指标的路由数 196 也属于同类人工统计漂移。

建议

  • 用 getter 源码生成 env 注册表，标注“读时解析 / 导入时固定”。
  • 给每个键补 默认 / 覆盖顺序 / 热更新 / 所属模块。
  • 为 configuration.json 建 JSON Schema，启动时校验。
  • 把本页生成脚本放进 CI，数字变化时自动开 PR。
