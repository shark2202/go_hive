2. 加载与依赖

惰性加载

  • import hive 只建映射，不导入框架。
  • 首次访问才 import_module。
  • __dir__ 合并 globals + __all__ + _EXPORTS。

extras

  • SSEResponse 需要 server extra（aiohttp）。
  • Colony/Worker 需要 tools extra。
  • 其余核心不依赖 extras。
  • 版本来自 importlib.metadata.version("aden-hive")。

3. 缺口

结构性问题

  • 没有逐导出的 stability/experimental 标记。
  • 没有导出级契约测试（签名/默认值/行为）。
  • _EXPORTS 与 __all__ 可能漂移（SSEResponse 就是例子）。
  • 派生项目难以知道哪些名字可安全依赖。

建议

  • 为每个导出加 stability 标记（stable/experimental/internal）。
  • 生成 API 文档与签名快照，CI 对比。
  • 把 __all__ 与 _EXPORTS 的一致性做成测试。
  • 给 extra-gated 导出单独的 import path。
