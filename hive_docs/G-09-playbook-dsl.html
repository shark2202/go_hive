Playbook DSL 契约
meta + worker + converge + lane + deadletter

仓库里已经有一份完整的 docs/playbook-spec.md；本页把它与当前代码（runner 签名、colony.db schema）对齐，做成可复用的契约表，并标出“已有 spec 但不在报告里”的事实。

0. 结论先行

Playbook 不是工作流引擎，而是在 Hive 进程内执行的 Python 编排脚本：meta 定义名字/并发，run(args) 是入口，worker/converge/lane 是注入 API。业务状态只在 Tracker，runner 不记“做到哪一行”，所以重跑即续跑。它不是沙箱，作者必须可信。

1. meta（3）

字段必填契约
name必填非空；规范化为文件名，最长 64

2. worker(...) 参数（11）

参数默认契约
task必填任务文本
profileNoneworker profile / 账号绑定
laneNone限速车道
skillNone技能名，追加到 task
retries0仅生命周期失败；attempts=retries+1
backoffNoneexp / linear；单次 ≤30s
timeout600等报告秒数
schemaNoneworker 侧回执契约；runner 不重校验
phaseNone接受但未转发；用 phase(title)
dataNone结构化数据
goalNoneUI 标题

返回 {status: done|failed, receipt, attempts, error}；只对生命周期失败重试。

3. converge(...) 参数（5）

参数默认契约
pending必填返回 undone rows；同步/异步
dispatch必填dispatch(unit,index)
max_rounds1最多轮数
circuit_breakerNone失败比例阈值
chunkcolony cap单轮并发

返回 {rounds, converged, remaining, dead_lettered}；停止时未完成行进入 deadletter。

4. lane / deadletter / log / phase

lane(name, concurrency=1, rate_per_min=None)

  • 每条 lane 独立信号量 + 启动间隔门。
  • 只能收窄并发，不能突破 colony cap。
  • 未声明 lane 会 warning 并按不受限处理。

其它注入

  • deadletter.list() / size / len()
  • log(msg) 只观测，不唤醒 Queen。
  • phase(title) 设置阶段标签并写日志。
  • tracker_query / tracker_count 同步，不 await。

5. 输入与状态

三种输入（互斥）

  • playbook：内联脚本；保存到 colony 库
  • playbook_path：磁盘路径；不复制
  • playbook_name：已保存名；重跑即续跑

四种状态

  • started：后台运行，返回 run_id
  • completed：结束，返回 result/dispatched/dead_lettered
  • failed：load 或运行失败
  • stopped：stop_playbook 取消
  • run-log 的 DB status 只有 done / error。

6. 持久化与安全

落盘

  • 脚本：colonies/<c>/playbooks/<name>.play.py；同名覆盖，无版本历史。
  • 运行日志：colony.db 的 playbook_runs。
  • 业务状态：tracker.db。
  • 重启会丢失正在运行的循环；已完成的 run-log 与 Tracker 状态保留。

安全

  • 在 Hive 进程内 exec，完整标准库/第三方包/文件/网络/env。
  • 不是沙箱；作者必须可信。
  • 同步阻塞会卡住事件循环。
  • Worker 工具集会剥掉 Queen-only 编排工具，防递归。

7. 缺口

已有但不在报告

  • docs/playbook-spec.md 已覆盖 DSL 全量；本页只是把它对齐到代码并纳入调研体系。
  • 真正缺的是“运行中恢复”：重启后需要手动重跑。
  • 没有脚本版本历史/回滚。

建议

  • 把 spec 的关键表纳入 07 章或独立章节，避免报告与 docs 双份漂移。
  • 为 playbook 增加内容哈希/版本字段。
  • 给 runner 加“当前 run 的持久化快照”，支持重启续跑。
