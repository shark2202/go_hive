7. 维护说明

这份 HTML 是工作底稿，不是最终章节

怎么更新

  • 数字变化：改对应行的“规模”，并在页脚更新“最后复核”。
  • 缺口关闭：点击状态列循环到“已完成”，或直接把行标灰。
  • 新增缺口：沿用 G-xx / C-xx 编号，不复用旧号。
  • 状态存在浏览器 localStorage 的 hive-gap-status-v1；换浏览器需重新标记。

统计口径与误差

  • EventType = 枚举成员数，精确。
  • env / CLI / 异常类 = grep 近似值，含少量注释或重复，仅用于排序。
  • 工具 104/866、路由 196、前端 230/65,649 来自 hive_docs/metrics.json。
  • “已穷举”只认逐实例表，不认“讲了机制”。
