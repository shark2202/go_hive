5. 发现与缺口

结构性观察

  • 866 个工具 = 866 段工具描述，是提示词之外最大的“行为文本面”。
  • 名称唯一，降低了跨 server 冲突；但不同 server 的同名语义仍可能冲突。
  • 工具是否 eager / searchable 不在此文件里，由 queen_tools_defaults 与 ToolTierState 决定。
  • 凭据依赖、破坏性、超时不在装饰器里，需要补充元数据才能做安全矩阵。

建议补齐的字段

  • server / category / eager|searchable / roles / credentials / destructive / timeout
  • 由 CI 对照 @mcp.tool 数量与 metrics.json，防止目录漂移。
  • 对 harness 的重复名，明确“同一 agent 只加载一个 group”还是允许并存。
